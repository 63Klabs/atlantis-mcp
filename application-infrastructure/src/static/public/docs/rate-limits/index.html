How it works

  • Public tier uses your IP address for rate limiting.
  • Authenticated tiers use your account identity, so limits follow you across IPs.
  • When a limit is exceeded, the server returns HTTP 429 with a Retry-After header.
  • All responses include X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset headers.
